# Rapport

À remplir à partir de l'étape E8 (mais tenir des notes au fil de l'eau).

Plan proposé :

1. **Introduction** — le problème, le modèle, l'enjeu énergétique.
2. **L'algorithme YDS** — présentation informelle, les 5 étapes, un exemple à la main.
3. **Modélisation en Lean** — tâches, ordonnancements, faisabilité, énergie ; le choix du temps
   discret.
4. **Preuves obtenues** — borne inférieure, terminaison, faisabilité, optimalité. Pour chaque
   résultat : l'énoncé, l'idée de la preuve, ce qui est prouvé et ce qui ne l'est pas.
5. **Vérificateur certifiant** — le principe, le théorème de soundness, le pont JSON.
6. **Résultats expérimentaux** — instances, énergie, comparaison à la borne.
7. **Limites et bilan** — `sorry` restants, ce qu'on ferait avec plus de temps.

Rappel : le rendu attendu est un programme Python, un projet Lean compilable, des exemples
vérifiés et un rapport expliquant les preuves obtenues.
